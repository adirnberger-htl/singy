# Github Setup

## Current State

This is a 5 man project for our school involving a sing language translator. It is currently empty, there is a pitch and a project proposal but no organization or such.

## What we need

We want to organize the team in a scrum like structure: We agreed on using the github issues as our backlog to write down all of the user stories. 

### A user story is always structured like this:

- As a [person] I want to [do thing] because [reason]. (full sentence; replace [*])
- List of things that need to be implemented for the user story to be considered done
- effort estimation (1 (very low) to 5 (fucking huge))
- priority (1 (low priority) to 5 (critical))

### The Github issue for each user story:

- Needs to be from a template user-storie.
- And can have sub issues for the case of bigger user stories that need to be made smaller.

## Your Task

You need to set up the infrastructure to make the next step of creating the user stories easier, set up templates (and such) and a github project to serve as our board to categorieze user stories into "To Do", "In Progress", "Done", "Reviewed".
